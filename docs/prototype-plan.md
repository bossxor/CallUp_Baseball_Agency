# 첫 시제품 구현 계획

[v0.6 구현 설계서](implementation-design.md)의 사무실과 스카우트 보고서 흐름을 검증한다.

| 담당 | 산출물 | 확인 기준 |
| --- | --- | --- |
| 게임 엔진 | 주차, 주간 요약, 사건, 세이브 검증 | 조용한 두 주 뒤 보고서 도착, 여러 주 진행 상한 4주, 중요 사건에서 정지, 저장 실패 시 마지막으로 저장된 주 유지 |
| 모바일 화면 | 사무실, 스카우트 보고서 | 현재 주차와 다음 행동을 확인하고, 버튼·스와이프로 보고서를 넘긴 뒤 사무실로 복귀 |
| 통합 | 실행 환경, 오프라인 Android 시제품 | 같은 웹 자산으로 APK를 빌드하고, 저장과 보고서 위치를 앱 재시작 후 복원 |
| 검증 | 엔진 테스트와 모바일 화면 테스트 | 작은 화면, 여러 주 진행, 뒤로 가기, 보고서 복원과 오류 표시 |

시제품은 고정된 시험 일정과 가상 선수를 사용한다. 실제 리그 시뮬레이션, 고객 계약과 시장은 [첫 플레이 버전 구현 순서](implementation-design.md#첫-플레이-버전)에 따라 다음 단위에서 구현한다. 출시용 그림과 배포 설정은 실제 화면과 플레이 흐름을 검증한 뒤 준비한다.
