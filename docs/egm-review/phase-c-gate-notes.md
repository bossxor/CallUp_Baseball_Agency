## 재현

- `node tools/check-phase-c-firstplay.cjs`
- `node tools/test-b1-assert.cjs`

- `powershell -NoProfile -ExecutionPolicy Bypass -File tools/build-callup.ps1 -SkipPatch`

서명된 `CallUp-Prototype.apk`는 `com.callup.agency`, 버전 162 / `0.1.0-callup.47`이다. 폰에 덮어 설치한 뒤 타이틀에서 기존 1년차 7월 저장을 확인했다.

## 실기기 스모크

같은 웹 번들을 넣은 별도 테스트 앱에서 고객 프로 선수 1명과 국내 유망주 8명이 든 저장을 가져왔다.

- 시즌 연봉 치트로 국내 선수 제안을 생성하고 협상과 선수 응답까지 확인했다. 연봉 최종 확정은 자동 검사의 성공 경로로 확인했다.
- 드래프트 치트로 홈과 이적 탭에 첫 계약 제안 5건이 표시됐다. 기기에서 최종 등록과 미지명 카드는 별도 확인이 필요하다.
- 장기 부상 지원을 선택하자 8,000만 원이 차감됐다. 이어 부진 지원을 보류해 추가 차감이 없는 것을 확인했다. 카드에 표시된 등급은 엔진의 유니크·레어 등급과 달랐으며, 지연 보고서는 자동 검사에서 확인했다.
- 홈·이적 제안·협상에서 `한국 1군`, 이적 제안에서 `팀 스타일 적합도`, `컨택 중심`, `주루 중심`을 확인했다. 축구 카피 검사는 실제 화면 문구를 조립하던 `{tier}부 리그` 템플릿도 검사한다.
