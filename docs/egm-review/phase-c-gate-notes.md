# Phase C 게이트

코드와 APK 빌드 검증 완료. 실기기와 첫 시즌 전체 진행 검증은 남아 있다.

| 게임 설계 완료 기준 | 확인 내용 | 상태 |
| --- | --- | --- |
| 국내 고객 2군→1군, 시즌 후 연봉 | 시즌말 카드 생성, 실제 협상 확정 경로, 연봉·주당 기준 수수료 1회. 국내 콜업부터 이어지는 전체 흐름은 별도 확인 필요. | 부분 확인 |
| 신인 드래프트 → 첫 계약 | 고객인 무소속 국내 유망주만 대상으로 지명·미지명, 신규 구단 등록을 확인. 드래프트 클래스가 구단을 만들거나 선수를 자동 영입하지 않음. | 엔진 통과 |
| 대만 스카우트 → 보고서 | 대만 후보 필터, 유료 파견, 보고서 생성, 저장·복구 결과 일치. 보고서 제스처와 홈 진입은 실기기에서 확인 필요. | 엔진 통과 |
| 미국 FA의 대만·일본 제안 비교 | 미·일·대 제안 생성과 협상 조건 조회, 한 곳 등록, 경쟁 제안 종료, 수수료 1회. | 엔진 통과 |
| 대만 선발 공백 대응 | 선발 장기 부상과 외국인 자리 여유를 각각 확인하고, 자격 있는 FA 투수 추천 후 다음 주에 제안 도착. | 엔진 통과 |
| 주요 사건에서 주차 진행 정지 | 드래프트 양쪽 결과, 시즌 연봉, 지원 도착·점검, 대만 추천 및 기존 제안이 진행 중 배치를 멈춤. 유니크 이상은 다음 조작 전 처리, 레어 지원은 경고 후 기본 선택. | 엔진·게이트 확인 |
| 장기 부상·부진 지원 | 자금 부족 시 안건 유지, 수락 시 회계 한 번 차감, 예정 주 점검 한 번, 보류 시 차감 없음. | 엔진 통과 |
| 자격·예산·자리 및 시즌 2 | 자격·예산·자리 부족 각각 등록 거부와 이유 확인. 시즌 2 개막까지의 실기기 연속 진행은 미확인. | 부분 확인 |

## 재현

- `node tools/check-phase-c-firstplay.cjs`
- `node tools/test-b1-assert.cjs`
- `powershell -NoProfile -ExecutionPolicy Bypass -File tools/check-soccer-residual.ps1`
- `powershell -NoProfile -ExecutionPolicy Bypass -File tools/build-callup.ps1 -SkipPatch`

서명된 `CallUp-Prototype.apk`는 `com.callup.agency`, 버전 157 / `0.1.0-callup.42`다. 패치 스크립트를 별도로 적용한 상태에서 `-SkipPatch`로 빌드했다.

실기기 연결이 끊겨 설치와 치트 화면의 시즌 연봉·드래프트·장기 부상·부진 버튼은 확인하지 못했다. 치트의 엔진 동작은 자동 검사로 확인했다. 드래프트 치트는 무소속 국내 유망주를 이미 고객으로 영입한 테스트 저장에서 사용한다.
