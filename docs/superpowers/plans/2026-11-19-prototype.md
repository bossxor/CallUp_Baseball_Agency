# 콜업 첫 시제품 구현 계획

최신 기준은 game-design.md와 implementation-design.md v0.6이다.

## 구현 범위

TypeScript 코어와 정적 모바일 웹 화면을 만든다. 실제 시즌의 경제와 경기 시뮬레이션에 앞서 사무실, 주차 진행, 스카우트 보고서, 읽은 위치 복구, 관심 등록과 면담 회신을 연결한다. 네 시장과 임시 선수는 시제품 데이터로 명시한다. Android 앱은 자체 WebView 래퍼로 로컬 자산을 실행하고 debug.keystore로 서명한다.

- [x] src/game.ts에 버전 있는 상태, 파견, 스냅샷 보고서, 후속 면담과 1~4주 진행을 구현한다.
- [x] src/main.ts와 src/style.css에 사무실, 내 선수, 스카우트와 시장을 연결한다. 실패한 저장은 현재 상태에 반영하기 전에 표시한다.
- [x] 종이색 #F3EFE5, 용지 #FFFCF5, 남색 #172C3D, 녹색 #23634B, 보조 글자 #5A665F, 구분선 #D4D6C8을 쓴다. 기기 기본 한국어 글꼴과 숫자 고정폭을 사용한다. 보고서의 큰 선수 이름과 구분된 기록 영역으로 시선을 모은다. 카드와 배지 반복 대신 주간 안건 목록과 한 장씩 읽는 용지를 사용한다.
- [x] 테스트에서 주차 재현, 0명 보고서, 중복 명령 방지, 저장 복구와 여러 주 진행 중단을 확인한다.
- [x] Android 전체화면, 뒤로 가기, 키보드, 로컬 저장을 연결하고 서명한 APK를 만든다.
- [x] 브라우저 또는 연결된 기기에서 파견에서 보고서와 면담 회신까지 진행한다.

## 검증 경계

시제품 경기 요약은 임시 기록이다. 네 리그 실제 경기·순위 집계, 한국 드래프트, 해외 등록, 선수 지원과 시즌 2는 후속 첫 플레이 버전 범위다.

## 확인 결과

- npm test에서 4개 테스트가 통과했다. 파견 비용, 동시 파견 제한, 보고서 도착 중단, 재현 가능한 진행, 읽은 장 복구, 면담 중복 방지, 계약 만료, 빈 보고서와 손상 데이터 거부를 확인했다.
- 브라우저의 375×812, 812×375 화면에서 가로 넘침과 44px 미만 버튼이 없었다. 대만 파견을 최대 4주 진행했을 때 복귀한 4주차에서 멈췄다. 두 번째 후보를 관심 등록하고 면담한 뒤 고객 계약했다. 새로고침 후 계약 고객과 보고서 2/2 위치가 복구됐다.
- Android APK에 제공된 debug.keystore의 androiddebugkey로 서명하고 서명을 검증했다. 요청한 Android 권한은 없다.
- 실제 기기 설치, 뒤로 가기와 키보드 확인은 ADB 연결 기기가 없어 남아 있다. Android 빌드와 서명 검증은 실제 기기 검증을 대신하지 않는다.

## 2026-11-19 실제 기기 검증

SM_S948N에 제공된 키스토어로 서명한 APK를 설치했다. 새 에이전시를 만든 뒤 대만에 파견하고 최대 4주를 진행했다. 보고서가 도착한 4주차에 중단했고, 보고서 두 번째 후보를 관심 등록하고 면담을 요청했다. 기기의 뒤로 가기로 사무실에 돌아왔고 5주차에 면담 회신을 받아 고객 계약했다. 앱 강제 종료 후 재실행해 천보위 고객 계약과 보고서 2장 위치가 유지되는 것을 확인했다. 기기의 네트워크 설정은 변경하지 않았다.

## 모바일 게임 화면과 플레이 동선

콜업의 플레이어는 에이전트다. 고객 여러 명을 발굴하고 선수와 구단의 우선순위를 조율한다. 선수 한 명의 경기 수행과 개인 육성을 중심에 두는 야구 커리어 게임과 플레이어 역할이 다르다.

사인히어 APK의 화면과 엔진에서 홈의 스카우트 복귀 알림, 후보별 보고서, 선수 상세의 영입·이적 행동, 경쟁 제안, 수수료와 다음 주 진행을 확인했다. 콜업은 사무실에서 파견 준비나 도착한 보고서를 바로 열고, 후보 카드에서 선수의 기록과 의견을 확인해 관심 등록과 면담으로 이어간다. 홈에 표시할 다음 선택은 미결 안건과 복귀 상황에 따라 달라진다.

타이틀에는 자체 야간 야구장 사진과 콜업 엠블럼을 사용한다. 사무실은 남색, 핵심 버튼은 동색을 사용한다. 선수 카드는 콜업의 가상 선수 초상, 소속, 실력 범위와 관찰 기록을 보여준다. 이 색상과 카드 구성은 설계서 v0.6의 종이색 시제품 방향을 수정한 결정이다.

고객 계약 이후의 플레이는 구현 설계서의 구단 수요, 복수 제안, 역제안, 등록과 수수료 순서로 확장한다. 한국 드래프트와 1·2군 등록, 일본·대만·미국의 가상 시장 규칙이 콜업의 야구 규칙을 결정한다.
