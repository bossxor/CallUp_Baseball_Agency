# Phase UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship CallUp-only dark amber visual identity, single-save title, vertical home feed with rarity gates, baseball CTA, and SignHere-grade craft — before Phase C gameplay.

**Architecture:** Token-first reskin via `callup-theme.css` + focused shell/home/nego layout patches (Node `tools/fix-ui-*.cjs` on minify assets, same pattern as residual). New logo/icon assets under `apk-src/assets/public`. No full React rewrite. Home swaps swipe stack for vertical feed + week-advance gate.

**Tech Stack:** `apk-src` WebView JS/CSS, `callup-theme.css`, Node patch scripts, `build-callup.ps1`, adb 2-min smoke.

**Spec:** [docs/superpowers/specs/2026-11-24-phase-ui-design.md](../specs/2026-11-24-phase-ui-design.md)

## Global Constraints

- Dark base + warm amber/leather accent. No sage-light theme residual on touched screens.
- Tier order: common < rare < unique < epic < legend.
- Unique+ blocks week advance. Common/rare: warn once then **safe-default** auto-resolve; **player copy says 「랜덤으로 선택」** (intentional mismatch — verify defaults in logs).
- Legend confirm = **3s hold** on choose button (not open dialog).
- Title: **1 save** + data reset only (no 3 slots / big main menu).
- Center tab CTA = baseball (or home-plate) silhouette, not diamond.
- Phase C (draft/salary season) **out of scope**.
- Default device gate = 2-min worldgen→home. Full week smoke only when phone free.
- Commit+push after each task batch when human standing rule applies.
