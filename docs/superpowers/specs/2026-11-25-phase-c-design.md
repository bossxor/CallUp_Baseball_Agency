### 드래프트와 Residual 관계

- Residual에서 **성남 야구고/아마추어 구단 슬롯** 제거됨.
- C2는 **아마추어 선수 풀(드래프트 클래스)** 로 지명 결과를 낸다. 구단 슬롯으로 아마추어를 되살리지 않음.
- 지명 안 되면 결과만 보고; 지명되면 첫 계약 협상 안건(유니크+ 권장) 생성.

### 시즌 후 연봉

- Residual **연봉(연봉/52 수수료)** 모델 사용.
- **신규 플로:** 시즌 결산 후 국내 소속 고객 대상 연봉 협상 안건. 기존 주중 재계약과 구분되는 시즌말 트리거.

## 4. 홈·티어 연동 (Phase UI)

| 안건 유형 | 권장 티어 | 주 진행 |
|-----------|-----------|---------|
| 드래프트 결과·첫 계약 | 유니크~레전드 | 유니크+ **막힘** |
| 시즌후 연봉 | 유니크 | 막힘 |
| 부상/부진 지원 | 레어~유니크 | 유니크면 막힘, 레어면 경고+기본지 |

레전드급(예: 운명적 첫 지명 계약)은 UI 스펙대로 **3초 홀드**.

## 6. 완료 게이트 C

game-design §첫 플레이 버전 완료 기준 **전항** + impl 단계 2·3 APK분:

- [ ] 국내 영입 → 2군/1군 기록 → 시즌후 연봉 협상 1회 완료
- [ ] 드래프트 지명 결과 확인; 지명 시 첫 계약까지
- [ ] 대만 스카우트 파견→보고서 유지 (회귀)
- [ ] 미·일·대 제안 비교 후 한 곳 등록, 수수료 1회 (회귀)
- [ ] 부상/부진 지원 선택 → 점검 주 보고함
- [ ] 자격·예산·자리 불일치 시 실패 이유 표시 (회귀)
- [ ] 드래프트 결과 등 중단 조건에서 홈 정지
- [ ] A·B·Residual·UI 회귀 (월드젠→홈, 피드 게이트)
