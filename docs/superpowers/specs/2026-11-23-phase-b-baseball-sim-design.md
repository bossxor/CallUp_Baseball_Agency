# Phase B — 야구 시뮬 코어 설계

**날짜:** 2026-11-23  
**선행:** Phase A 완료 (`0.1.0-callup.4`)  
**상위:** [new-game-roadmap-design.md](2026-11-23-new-game-roadmap-design.md) §4  
**상태:** 세이브 **B1** · 포지션 **풀 9** · **사인히어/축구 잔향 전량 제거** 확정.

---

## 1. 목표

야구는 축구와 다른 스포츠다. 내부 포지션·능력·기록·경기 집계·로스터 수요가 **야구 규칙**으로 읽혀야 한다.  
저장/UI에 축구 스키마(`GK`/`DF`/`MF`/`FW`, `gk`/`sho` 등)가 남지 않는다.

## 2. 세이브 — B1 확정

- 축구 스키마 세이브 **로드 거부** + 새 게임 안내.
- 마이그레이션 없음.

## 3. 포지션 — 풀 9 확정

| 코드 | 라벨 |
| --- | --- |
| `P` | 투수 |
| `C` | 포수 |
| `1B` | 1루수 |
| `2B` | 2루수 |
| `3B` | 3루수 |
| `SS` | 유격수 |
| `LF` | 좌익수 |
| `CF` | 중견수 |
| `RF` | 우익수 |

- 월드 생성·스카우트 필터·구단 수요·기용·UI가 **동일 표**를 쓴다.
- 선발 XI(11) / 축구 포메이션 가정은 깨고, 야구 **수비 9 + 투수 운용**(선발/불펜은 능력·역할 플래그로, 포지션 코드는 `P` 유지)으로 맞춘다.
- 공수 예상: 4코드 대비 약 **2~3×**. 맵·분기·수요 배열을 9칸으로 확장하는 패치. 엔진 전면 재작성은 하지 않는다.

## 4. 능력 키

축구 키 폐기. UI 노출 축(최소):

| 축 | 키(가칭) | 비고 |
| --- | --- | --- |
| 타격 | `bat` | 필요 시 contact/power는 내부 파생 |
| 투구 | `pit` | `P` 주력 |
| 수비 | `fld` | 포지션별 가중 |
| 주력 | `spd` | |

포지션별 가중 표(`Rt`)를 9코드용으로 재작성.

## 5. 기록

- 타자: 타석, 안타, 출루·장타(또는 분자/분모), 타점  
- 투수: 이닝(내부 아웃 수), 삼진, 볼넷, 자책/평균자책  
- 한 경기 팀 승패와 선수 기록 정합

## 6. UI·카피

카드·리그·보고서·주간·스카우트 필터가 9포지션·야구 기록만 표시.  
구 세이브 핑거프린트(`GK` 등)로 B1 거부.

## 7. 비범위

- 플레이어 직접 경기 조작  
- 네 시장 동시 고도화  
- Phase C 드래프트/연봉  
- 크레스트 픽셀 전량 재작화  
- DH 규칙 시장별 분기(필요하면 후속; 기본은 단순 타석 모델)

## 8. 게이트

1. 신규 세이브/UI에 `GK`/`DF`/`MF`/`FW` 및 축구 스탯 키 노출 0  
2. 9포지션이 생성·필터·수요·카드에 등장  
3. 타/투 야구 기록 표시, 경기 합 모순 없음  
4. 새 게임 → 4주 → 저장 → 재실행  
5. 구 세이브 로드 거부  
6. Phase A `check-identity` 회귀  
7. **퍼지:** `apk-src` 사용자 자산 + 엔진/셸에서 사인히어·축구 잔향 **전량 0** (아래 §8.1). Activity smali 경로 `com.signhere.offline`은 사용자 미노출이면 허용 목록에만 남기거나, B 끝에서 rename 티켓으로 제거

### 8.1 퍼지 목록 (완료 시 전부 0)

문자열/키 grep 대상(허용 목록 외):  
`사인히어`, `SignHere`, `Sign Here`, `SIGN HERE`, `Football`, `풋볼`, `축구`, `GK`, `DF`, `MF`, `FW`(포지션 코드), `gk`/`sho`/`pas`/`dri` 등 축구 능력 키(새 스키마 키로 대체 후 잔존 0), `해트트릭`, `매치볼`, `이적료`(계약금으로), 축구 씬 파일명 잔존이 UI에 노출되는 경우.

허용: 개발 주석의 역사 기록 1줄, Manifest Activity 클래스명(미노출 시), `check-identity`/`phase-*-gate` 문서 본문.
