## 1. 목적

사인히어 포크 후 밝고 옅은 세이지 테마로 **싸 보이고 안 읽히는** 문제를 닫는다.  
콜업 **전용** 다크·앰버 룩으로 바꾸고, 홈 안건 UX를 피드+게이트로 재구성한다.  
완성도 기준: **사인히어급 공예** (복제 아님).

목표 문장: **다른 얼굴의 콜업 — 같은 에이전시 손맛은 남기되, 형제 게임 티는 홈·탭·타이틀에서 끊는다.**

---

## 2. 로드맵 위치

```text
A 정체성 → B 야구 시뮬 → Residual → Phase UI → C 플레이 기능
```

- Phase UI는 **기존 C를 대체하지 않음.** C 범위(드래프트·연봉·부상지원)는 그대로 뒤로.
- “새 게임” 로드맵 종료 조건은 이후 **A ∧ B ∧ UI ∧ C** 로 갱신 (로드맵 문서 패치).

---

## 3. 정체성 · 비주얼

| 항목 | 결정 |
|------|------|
| 기준 | 콜업 신규 아이덴티티 (사인히어 복구 아님) |
| 톤 | 에이전시 오피스 + 고대비·정보 위계 |
| 밝기 | 다크 계열 (순흑 필수 아님, 라이트보다 분명히 어둡게) |
| 액센트 | 웜 앰버·가죽/흙 |
| 티어 색 | 커먼 → 레어 → 유니크 → 에픽 → 레전드 (토큰화) |
| 범위 | 토큰·타이포·5화면 + 로고·키 아트·아이콘 |
| 구현 전략 | `callup-theme.css` 토큰 재작성 + **홈·협상 레이아웃 깊게** + 에셋 교체. 전 UI 프레임워크 재작성 금지 |

**손대는 화면:** 타이틀 · 등록 · 인게임 홈(피드) · 협상 · 선수목록.

## 4. 타이틀 · 세이브

- 슬롯 3개 / 큰 메인메뉴 **없음**
- **세이브 1개:** 있으면 이어하기, 없으면 새 게임
- **데이터 초기화**만 별도 (확인 다이얼로그 1회)

---

## 5. 인게임 홈 — 세로 피드 + 게이트

### 5.1 정보 구조

- 기존 **좌우 카드 스와이프 스택 폐기**
- **세로 피드:** 대기 안건 목록 → 탭 → 상세/선택
- 하단 가운데 CTA: 다이아 → **야구공(또는 홈플레이트)** — 주 진행
- 홈/협상 핵심 CSS·JS 클래스 **rename** + 레이아웃 변경 (rename만으로 끝내지 않음)

### 5.2 티어

`common < rare < unique < epic < legend`

- 목록·카드 좌측/보더 등으로 티어 색 표시
- **레전드 확정 조작:** 선택 버튼 **3초 홀드** (짧게 탭 ≠ 확정). 열 때 확인 아님.

### 5.3 주 진행 게이트

| 남은 안건 | 주 진행 (야구공) |
|-----------|------------------|
| 유니크 · 에픽 · 레전드 ≥1 | **불가** + 사유 표시 |
| 커먼 · 레어만 | **경고 1회** 후 진행 허용 |
| 없음 | 즉시 진행 |

**커먼/레어 경고 후 진행 시 자동 처리 (의도적 카피·동작 불일치):**

- **플레이어 문구:** 「아직 남은 안건이 있습니다. 진행하면 **랜덤으로 선택**됩니다.」
- **실제 엔진:** 각 안건의 **안전 기본지**(거절/보류/닫기 등)로 처리. 균등 랜덤 아님. 선택 UI·연출 없음.
- 제품 의도: 경고 압박은 “랜덤” 카피로, 밸런스·배신감은 기본지로 흡수. **스펙·치트/디버그에 실제 동작 명시.**

안전 기본지 매핑은 구현 플랜에서 이벤트 kind별 표로 고정 (본 스펙: “해당 안건의 보수적 기본 옵션”).

---

## 6. 협상 · 기타 화면

- 협상: 다크·앰버 토큰 + 대비·터치 타깃·위계. 손패/수락 배치는 가독성 기준으로 조정 가능 (플랜에서 샷 기준).
- 등록·선수목록: 동일 토큰·타이포. 레이아웃 대공사 없음 (홈·협상 우선).

---

## 7. 검증 게이트 (Phase UI)

- [ ] 타이틀: 세이브 1 + 초기화만. 슬롯3/대형 메뉴 없음
- [ ] 등록·홈·협상·선수목록 샷이 다크·앰버·고대비 (라이트 세이지 잔재 없음)
- [ ] 홈이 세로 피드. 스와이프 스택 UX 없음
- [ ] 가운데 CTA가 야구공(또는 홈플레이트) 실루엣
- [ ] 유니크+ 미처리 시 주 진행 불가
- [ ] 커먼/레어만 남았을 때 경고 문구에 「랜덤으로 선택」 포함, 진행 후 **기본지**로 처리됨 (유닛/로그로 확인)
- [ ] 레전드 선택: 3초 홀드 미달 시 미확정
- [ ] 로고·주요 탭 아이콘이 콜업 에셋 (사인히어 잔여 아이콘 0 on 해당 화면)
- [ ] A·B·Residual 회귀: 새 게임 월드젠 → 홈 진입 (2분 스모크)

## 9. 리스크

| 리스크 | 완화 |
|--------|------|
| minify 클래스 rename 누락 | 플랜에 심볼 표 + build 후 문자열 게이트 |
| “랜덤” 카피 vs 기본지 동작 | 스펙·게이트에 명시, QA는 로그/치트로 기본지 검증 |
| 홈 피드 공수 폭주 | 스와이프 제거 + 목록/상세 최소 DOM 재사용 |
| 폰 점유 스모크 | 기본 게이트 = 2분 월드젠→홈. 주 진행 풀게이트는 폰 빌 때 |
