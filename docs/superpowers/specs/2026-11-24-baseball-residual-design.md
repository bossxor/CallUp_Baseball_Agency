# 축구 잔여 → 야구 정렬 설계

**날짜:** 2026-11-24  
**작업선:** 사인히어 오프라인 APK 포크 (`T:\CallUp\apk-src`)  
**상위:** [new-game-roadmap-design.md](2026-11-23-new-game-roadmap-design.md) · [game-design.md](../../game-design.md)  
**상태:** 승인됨. 구현 플랜 작성.

관련 감사: 엔진/셸 키워드 잔여(주급·임대·유럽 클럽·월드컵 등). `/graphify`는 본 범위에 불필요(키워드·패치 중심).

---

## 1. 목적

Phase B 이후에도 남은 **축구 기준 시스템·카피**를 야구 에이전시(콜업)로 맞춘다.  
플레이어가 구단·연봉·시장 창·국제대회·계약 조항을 보고 축구로 읽지 않게 한다.

로드맵 Phase C(드래프트·시즌후 연봉 협상 신규 플로)는 **별도**. 본 문서는 포크에 이미 있는 루프를 야구화하는 잔여 정리 + 최소 추가다.

---

## 2. 구현 방식

패키지 단위로 설계→플랜→APK. 빅뱅 금지. 패치는 `tools/*.cjs` + 기존 빌드 훅.

| # | 패키지 | 한 줄 |
| --- | --- | --- |
| 1 | 구단·시장 | 한·일·대·미 + 이름 편집 |
| 2 | 연봉 | 주급→연봉, 주 수령 ÷52 |
| 3 | 달력·창 | 이적시장→트레이드/FA, 데드라인 |
| 4 | 국제대회 | WBC 등 5종 카피·트리거 |
| 5 | 계약 조항 | 임대·셀온 삭제, 위약금·옵트아웃 |
| 6 | 용어 | 주전/메디컬/유소년 등 |
| 7 | 비시즌 선택 | 전지훈련 vs 아카데미 안건 |

권장 구현 순서: **1 → 2 → 5 → 3 → 4 → 6 → 7** (구단·돈이 먼저, 카피성 뒤).

---

## 3. 구단·시장

### 3.1 확정

- 시장: **한국 · 일본 · 대만 · 미국만**. 유럽 등 리그 슬롯 삭제·병합.
- 구단 수: 한 10 / 일 12 / 대 6 / 미 메이저 30.
- 기본명: `data/callup-clubs.json` 가상명. 미국 30은 **도시 가명**을 JSON에 추가(신규 작성).
- 소스 전략: 기존 콜업 데이터 재사용(C) + 개인이 이름 변경.
- 이름 편집: 시제품 리그 화면 **일괄 편집·기본값 복구**를 APK에 이식. 세이브에 커스텀명 저장.
- 한국 티어: **1군 · 2군만**.
- 일본: 1군 · 2군. 대만: 1군. 미국: **메이저 + 마이너 1단계**(AA/AAA 분리 없음).

### 3.2 제외

- **성남 야구고** 및 한국 **아마추어 구단 슬롯** — 제거. (시제품 드래프트 더미였음. 드래프트 자체는 Phase C.)
- 실명 라이선스, 신규 크레스트 아트, AA/AAA 3단.

### 3.3 게이트

- UI·월드에 유럽 클럽명(맨시티·레알 등) 사용자 노출 0.
- 4시장 구단 수만 설계 수치와 일치.
- 구단명 편집 → 홈/선수/협상 표시에 반영. 기본값 복구 동작.

---

## 4. 연봉

### 4.1 확정

- 저장·협상 금액 = **연봉(연)**. 라벨 `주급` → `연봉`.
- 주간 에이전시 수입 = `연봉 / 52 × 수수료율` (주 단위 루프 유지).
- 계약 성사 수수료·계약금은 연봉과 별도. 주급 환산용 `*52`는 연봉 기준으로 정리.
- 구(축구) 주급 세이브: **로드 거부**(B1과 동일 계열). 과대 연봉 오인 방지.

### 4.2 비범위

- Phase C 국내 시즌후 연봉 협상 **신규** 플로.

### 4.3 게이트

- 협상 UI에 `주급` 0(허용: 주간 수입 설명 문장에 “연봉의 1/52” 정도).
- 주 진행 시 수수료가 연봉÷52 기준인지 치트/로그로 확인.

---

## 5. 달력·창

### 5.1 확정

- `여름/겨울 영입` → 시즌중 **트레이드 기간**, 오프시즌 **FA·재계약 기간**.
- `데드라인 데이` → **트레이드 데드라인**. 시계 자정 유지. 미니게임 골격 유지, 카피만 야구.
- 시즌 흐름: 프리시즌 → 정규 → 결산 → 오프. 달력 엔진 전면 재작성 금지. 기존 주차 훅에 라벨·창 조건만.

### 5.2 비범위

- 시장별 실제 KBO/MLB 등록일 풀 시뮬.

---

## 6. 국제대회

### 6.1 확정 (5종)

월드컵/FIFA/UEFA 잔여를 아래로 치환:

1. WBC  
2. 프리미어12  
3. 아시안게임  
4. 올림픽  
5. **아시아야구선수권** (대륙 국가대표 선수권)

**APBC**(아시아 프로야구 챔피언십)는 규모상 이번 제외.

### 6.2 구현 깊이

- 기존 국제대회 주차/플래그 훅 재사용. 새 토너먼트 브래킷·메달 UI 없음.
- 효과: 소집·평판·뉴스 수준(기존과 동등).

---

## 7. 계약 조항

### 7.1 확정

| 조항 | 처치 |
| --- | --- |
| 임대 | **삭제** (야구에 없는 축구 임대) |
| 셀온 | **삭제** |
| buyout / 위약금 | **유지**. 라벨을 계약 해제·위약금 쪽으로 |
| 옵트아웃 | **추가**. 계약에 발동 가능 연도 플래그. 발동 시 자유계약·재협상 훅. UI는 조항 표시 + 발동 안건 최소 |
| 계약금 | 연봉과 병행. `*52` 정리는 §4 |

### 7.2 비범위

- MLB 옵션/DFA 풀 규칙, 포스팅 시스템 신규.

---

## 8. 용어

| 기존 | 치환 |
| --- | --- |
| 주전 / 벤치 | 선발·주전 출전 / 벤치·대타·불펜. 한·일은 1군·2군 병기 |
| 메디컬 | 메디컬 체크 / 신체검사 |
| 유소년 / 아카데미 | 아마추어·육성 (시설·이벤트 **카피**). 한국 아마 구단 슬롯은 없음 |

아카데미 **시스템 삭제·재구축**은 비범위. §9 비시즌 선택만 최소 추가.

---

## 9. 비시즌 선택 이벤트 (추가)

오프시즌 주차에 고객(또는 주요 고객) 대상 안건:

- 선택: **전지훈련** / **아카데미·동계 육성** / 스킵.
- 효과(최소): 전지훈련 → 컨디션·개막 준비 보너스. 아카데미 → 성장·노출 쪽. 수치 과함 금지.
- UI: 기존 안건·선택지 훅. 새 전용 화면·미니게임 없음.

---

## 10. 세이브·회귀

- 야구 스키마 + 본 패치 이후 세이브만 지원. 유럽 클럽·주급 스키마 로드 거부 또는 새 게임 유도.
- 각 패키지 APK 후: 새게임 → 수 주 진행 → 저장 → 재실행 스모크.
- 기기 게이트 스크립트는 패키지마다 최소 항목만 추가.

---

## 11. 비범위 총괄

- Phase C 드래프트·국내 시즌후 연봉 신규 플로
- smali `com.signhere.offline` 경로 rename
- 크레스트·씬 아트 전량 재작화
- AA/AAA, APBC, 아시아야구선수권 외 소규모 대회
- `/graphify` 필수화

---

## 12. 성공 기준

1. 구단·리그 화면이 한·일·대·미 야구로만 읽힘. 이름 편집 가능.  
2. 협상·주간 수입이 연봉 기준.  
3. 이적시장·월드컵·임대·셀온 사용자 노출 0(의도적 잔여 목록 없으면).  
4. 위약금·옵트아웃이 계약에서 보임. 옵트아웃 발동 시 재협상 기회.  
5. 오프시즌에 전지훈련/아카데미 선택 안건이 뜸.

---

## 13. 합의 로그 (요약)

- 구단: C(기존 JSON) + 이름 편집. 미국명 A(도시 가명 30). 유럽→4시장 A. 미국 티어=메이저+마이너1. 성남/한국 아마 구단 제거.
- 연봉·달력: 섹션 승인.
- 국제: WBC·프리미어12·아시안게임·올림픽·아시아야구선수권. APBC 제외.
- 조항: 임대·셀온 삭제, 위약금 유지, 옵트아웃 A.
- 용어 승인. 비시즌 전지훈련/아카데미 선택 추가.
